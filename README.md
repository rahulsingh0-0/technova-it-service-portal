# TechNova IT Service Portal

A ServiceNow IT Service Management (ITSM) project built in a Personal Developer Instance (PDI) to practice and demonstrate ServiceNow System Administration and ITSM configuration.

## 🎯 Project Overview

TechNova is a simulated organization used to build a practical ServiceNow environment for managing IT service operations, user access, record security, form behavior, notifications, and administrative automation.

The project focuses on **CSA / ITSM / System Administrator-level configuration and scripting**.

## 🛠️ ServiceNow Skills Demonstrated

* User and Group Administration
* Roles and Access Control Lists (ACLs)
* Incident Management
* Business Rules
* Client Scripts
* UI Policies
* UI Actions
* Notifications
* Scheduled Jobs
* Basic GlideRecord scripting
* Form and List Configuration
* Data Validation
* Access and Permission Testing
* Configuration Troubleshooting

## 🔐 Access Control

Implemented and tested the relationship between:

**User → Group → Role → ACL → Permission**

Access was tested using different user scenarios to verify that users could access only the records and functionality permitted by their roles and ACL configuration.

## ⚙️ Automation & Scripting

Configured Business Rules for server-side record processing using:

* `current`
* `previous`
* `gs`
* Conditional logic
* Basic GlideRecord operations

Client-side configuration was implemented using Client Scripts and UI Policies to control form behavior and improve data entry.

## 🔔 Notifications & Automation

Configured Notifications and Scheduled Jobs to support service-related communication and time-based administrative automation.

## 🧪 Testing

Testing was performed after configuration changes to validate:

* User access and permissions
* ACL behavior
* Business Rule execution
* Client-side form behavior
* UI Policy behavior
* UI Actions
* Notifications
* Scheduled automation
