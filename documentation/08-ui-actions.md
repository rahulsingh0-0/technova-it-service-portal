# UI Actions

## Objective

Configure UI Actions to provide users with buttons and actions directly on ServiceNow forms.

## Purpose

UI Actions can be used to:

- Create form buttons
- Create related links
- Execute actions from a record
- Improve user interaction with forms

## Example

A UI Action can be configured to allow an authorized user to perform a specific action on an Incident directly from the form.

## Configuration

A UI Action can be configured using:

- Name
- Table
- Action name
- Form button
- Form context menu
- List context menu
- Condition
- Script

## Conditions

Conditions can be used to control when a UI Action is displayed or available to the user.

## Testing

UI Actions were tested from the relevant ServiceNow form to verify that:

- The action appears under the expected conditions.
- The action is hidden when its conditions are not met.
- The expected operation occurs when the action is selected.
