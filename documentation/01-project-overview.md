# TechNova IT Service Portal — Project Overview

## Project Objective

TechNova is a simulated organization used to build a practical ServiceNow IT Service Management (ITSM) environment.

The project demonstrates ServiceNow configuration, administration, access control, automation, and basic scripting using a Personal Developer Instance (PDI).

## Project Scope

The project focuses on:

- User and group administration
- Roles and access control
- Incident Management
- ACL configuration
- Client-side configuration
- Business Rules
- Notifications
- Automation
- Basic ServiceNow scripting
- Testing and validation

## Platform

- ServiceNow Personal Developer Instance (PDI)
- ITSM / System Administrator scope

## Key Objective

The goal is to demonstrate practical ServiceNow CSA-level and System Administrator skills through a hands-on ITSM implementation rather than only theoretical knowledge.
