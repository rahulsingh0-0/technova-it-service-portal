# Testing & Validation

## Objective

Test the configured ServiceNow functionality to verify that the system behaves as expected.

## Testing Approach

Each configuration was tested after implementation to confirm that the expected result occurred.

## Areas Tested

### Access Control
- Verified access for authorized users.
- Verified restricted access for unauthorized users.

### Incident Management
- Created and updated Incident records.
- Verified priority and assignment behavior.
- Tested Incident state transitions.

### Business Rules
- Tested Before Business Rules.
- Tested After Business Rules.
- Tested Async Business Rules.
- Verified expected server-side actions.

### Client Scripts
- Tested form behavior on load.
- Tested field changes.
- Tested form submission validation.

### UI Policies
- Verified mandatory, read-only, and visibility behavior.

### UI Actions
- Verified action visibility based on conditions.
- Verified the expected action when selected.

### Notifications
- Verified that notifications were triggered when configured conditions were met.

## Validation

Testing was performed using different record conditions and user access levels to confirm that configurations worked as intended.

## Skills Demonstrated

- Functional testing
- Configuration validation
- Troubleshooting
- Access testing
- ITSM process validation
