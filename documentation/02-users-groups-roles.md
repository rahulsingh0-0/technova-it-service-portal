# Users, Groups & Roles

## Objective

Configure users, groups, and roles in ServiceNow to demonstrate basic access and user administration.

## Users

The project includes users representing different IT service roles.

Example users:

- Deepak Singh — IT Administrator
- Shiraj — IT User

## Groups

Groups are used to organize users according to their responsibilities.

Example groups:

- IT Support
- IT Administration

## Roles

Roles control what users are allowed to access and perform in ServiceNow.

Examples:

- `itil` — ITSM user capabilities
- `admin` — Administrative access

## Access Model

The basic access relationship is:

User → Group → Role → Permission

Users are assigned to appropriate groups, and groups can provide the required roles for performing ITSM activities.

## Testing

Access was tested using different user accounts to verify that users receive the expected permissions based on their assigned roles.

## Skills Demonstrated

- User administration
- Group management
- Role assignment
- Access management
- Basic ServiceNow security concepts
