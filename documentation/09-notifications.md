# Notifications

## Objective

Configure email notifications to keep users informed when important Incident events occur.

## Purpose

Notifications can be used to inform users when:

- An Incident is created
- An Incident is assigned
- An Incident is updated
- An Incident is resolved

## Notification Configuration

A notification can be configured using:

- Name
- Table
- When to send
- Conditions
- Recipients
- Email subject
- Email body

## Example

An Incident notification can be configured to notify the appropriate user or support group when an Incident is assigned or its status changes.

## Conditions

Conditions determine when the notification should be triggered.

This prevents unnecessary emails and ensures that relevant users receive useful information.

## Testing

Notifications were tested by performing the relevant Incident actions and verifying that the configured notification was triggered as expected.
